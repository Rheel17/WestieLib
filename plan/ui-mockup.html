WestieLib UI mockup

These are static screens of the Win32 main window. Each window is drawn at 1280×800 with the Windows 10 light palette. The spec is ui.md.

Every element maps to a stock Win32 control or an owner-drawn one. Covers are placeholders, and the data is a fake library of 100 tracks in 4 playlists. Every screen renders from that same data, so the counts agree across the panels.
